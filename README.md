✨ Visão Geral do Projeto
<br>
Este projeto é uma Landing Page moderna e convidativa desenvolvida para uma sorveteria, com foco em criar uma experiência visual deliciosa e intuitiva para o usuário.
<br><br>
O layout utiliza cores claras e vibrantes (destacando o rosa e o branco) para transmitir a alegria e o frescor dos sorvetes. Além da beleza estética, o projeto é 100% Responsivo, garantindo que a página seja acessível e funcional em qualquer dispositivo.
<br><br>
💻 Tecnologias Utilizadas
<br>
Este projeto foi construído utilizando as principais tecnologias do front-end:
<br><br>
HTML5: Para a estrutura base e semântica da página.

CSS3: Para a estilização, layout e responsividade completa.

JavaScript: Para adicionar interatividade, como:
<br><br>
Funcionalidades de Menu: Criação de um menu hamburger ou dropdown interativo para mobile.
<br><br>
Animações: Efeitos de fade-in ou scroll para tornar a experiência mais dinâmica.
<br><br>
Carrinho/CTA Interativo (se aplicável): Lógica básica para botões de compra.
<br><br>
💡 Destaques e Funcionalidades
<br>
Responsividade Total: O design se adapta perfeitamente a dispositivos desktop, tablet e mobile .
<br><br>
Seção Hero Atraente: A seção inicial "BEM VINDO AO NOSSO MUNDO DOS SORVETES" combina tipografia forte com ilustrações de sorvetes apetitosos, incentivando a ação (Comprar agora).
<br><br>
Navegação Clara: Menu superior simples com as principais seções (Home, Menu, Categorias, Contatos).
<br><br>
Integração Social: Links para redes sociais no rodapé ou na seção de destaque.
<br><br>
Foco na Experiência do Usuário (UX): Uso de cores quentes e texto envolvente para motivar o usuário.
<br><br>
